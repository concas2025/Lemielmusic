# Lemielmusic

Ứng dụng nghe nhạc YouTube Music tối giản, giao diện kính mờ (frosted glass) dành cho iOS.

## Tính năng
- **Khám phá & Tìm kiếm:** Tìm kiếm và phát nhạc trực tiếp từ YouTube Music (hỗ trợ stream MP4/AAC tương thích mượt với iOS `AVPlayer`).
- **Giao diện kính mờ (Glassmorphism):** Hiệu ứng blur theo màu bìa đĩa bài hát đang phát.
- **Phát nhạc nền iOS:** Hỗ trợ phát khi tắt màn hình, điều khiển từ Lock Screen & Control Center.
- **Lời bài hát đồng bộ (Synced Lyrics):** Tự động lấy lời bài hát từ LrcLib, chạm vào từng câu để tua.
- **Thư viện cá nhân:** Lưu bài hát yêu thích, lịch sử nghe và lịch sử tìm kiếm ngay trên thiết bị.

## Cài đặt trên iPhone (`.ipa`)
1. Vào mục **Releases** ở cột bên phải và tải file **`Lemielmusic.ipa`** mới nhất.
2. Cài đặt lên iPhone bằng công cụ tự ký chứng chỉ bạn đang dùng (**SideStore**, **AltStore**, **Sideloadly**, **ESign**, hoặc **TrollStore**).
3. Nếu dùng chứng chỉ Apple ID miễn phí (AltStore/SideStore/Sideloadly), vào *Cài đặt -> Cài đặt chung -> VPN & Quản lý thiết bị* để **Tin cậy** chứng chỉ sau khi cài.
